# Changelog

## manymome.table 0.4.1

CRAN release: 2026-07-19

- Minor updates to the README page and DESCRIPTION. (0.4.1)

## manymome.table 0.4.1

CRAN release: 2026-07-19

- Updated to print SE-based confidence intervals and *p*-values when a
  path has no mediator and effect not standardized. (0.3.2)

- The optional arguments (`...`) of
  [`as_flextable.cond_indirect_effects()`](https://sfcheung.github.io/manymome.table/reference/as_flextable.cond_indirect_effects.md)
  and
  [`as_flextable.indirect_list()`](https://sfcheung.github.io/manymome.table/reference/as_flextable.indirect_list.md)
  are now passed to
  [`flextable::autofit()`](https://davidgohel.github.io/flextable/reference/autofit.html)
  when preparing the final output. (0.3.1)
